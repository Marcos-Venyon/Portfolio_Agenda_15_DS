## Descrição do Portfólio
Este projeto consiste na evolução de um portfólio web pessoal desenvolvido para apresentar de forma moderna, limpa e responsiva a minha trajetória acadêmica, habilidades técnicas e projetos práticos. O site foi estruturado para atender aos padrões profissionais, integrando tecnologias web atuais e navegação otimizada.

## Tecnologias Utilizadas
- **HTML5:** Estruturação semântica de todo o conteúdo da página.
- **CSS3:** Estilização customizada, microinterações, animações e efeitos visuais.
- **Bootstrap 5:** Framework CSS para grid responsivo, componentes de cards, tabelas e gerenciamento nativo de temas.
- **Bootstrap Icons & Devicon:** Biblioteca de ícones interativos e logotipos oficiais de linguagens de programação e ferramentas.
- **JavaScript (Vanilla):** Lógica para manipulação do DOM, armazenamento de preferências de tema no navegador (`localStorage`) e alternância dinâmica entre modo claro e noturno.
- **GitHub Pages:** Hospedagem e publicação contínua da aplicação web.

## Funcionamento do Projeto
O portfólio foi estruturado em formato *Single Page Application* (SPA) com navegação fluida:
1. **Menu de Navegação Superior (Navbar Sticky):** Permite alternar rapidamente entre as seções e possui o botão interativo para troca de tema.
2. **Seção Perfil (Hero):** Apresenta uma introdução visual com foto, nome e resumo dos objetivos acadêmicos e profissionais.
3. **Seção Formação & Idiomas:** Exibe de forma compacta e organizada a graduação (UNIVESP), o curso técnico (ETEC) e os idiomas estudados.
4. **Seção Habilidades Técnicas:** Demonstra o domínio em linguagens (HTML/CSS, Python, C++, Java e Bootstrap) acompanhadas de barras de progresso dinâmicas e ícones oficiais do Devicon.
5. **Seção de Projetos:** Cards com efeitos de transição em *hover* destacando os principais repositórios e tecnologias aplicadas.
6. **Seção de Contato:** Contém um formulário responsivo para envio de mensagens e links diretos com ícones para o **GitHub** e **LinkedIn**.

## Recurso Novo Adicionado
Para elevar o projeto acima do modelo base de aula, foram incorporados recursos avançados:
1. **Alternador de Modo Claro / Noturno (Dark Mode / Light Mode):** Um botão interativo no menu que altera o esquema de cores da página inteira e salva a preferência do usuário no armazenamento local do navegador.
2. **Ícones Tecnológicos Dinâmicos (Devicon):** Inclusão de ícones oficiais estilizados nas barras de competências e nos cards de projetos.
3. **Animações e Efeitos Visuais (Hover & Transitions):** Microinterações CSS nos cards (`transform: translateY` e sombras dinâmicas) e transições suaves de cores na alternância de temas.
